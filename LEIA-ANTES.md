# Histórico inativo

Estes documentos e scripts preservam decisões e a implementação específica de lotes anteriores. Não são uma fila de postagem nem autorização transferida. Scripts foram guardados como `.txt` porque alguns aprovavam IDs fixos com base em instruções do chat original, escreviam datas fixas ou usavam @gta.takes. O destinatário deve adaptar a lógica a um novo lote e obter sua própria aprovação antes de executar qualquer equivalente.

O README original descreve estados antigos (incluindo câmera de 780 px e edição anterior); use o README e a skill atual da pasta projeto. Registros de publicação são evidência histórica pública, não previsão de que uma postagem futura já ocorreu. Snapshots JSON estão marcados como historicalOnly.
